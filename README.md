# Operating System 2026 Spring (Operating-System-26SP)

本仓库包含了 2026 年春季学期操作系统原理与设计课程的所有课堂笔记、课程作业及实验代码。

## 🌱 分支说明

- **`master` 分支**：用于存放课堂笔记（`Notes`）和课程作业（`Homework`）。
- **其它分支**：用于存放每次实验的完成代码（每个实验对应一个独立分支）。

## 📂 目录结构 (master 分支)

- **`Homework/`**: 包含平时课程作业的解答及相关文档。
- **`Notes/`**: 包含每次课堂笔记的 Markdown 源文件及随堂记录。
