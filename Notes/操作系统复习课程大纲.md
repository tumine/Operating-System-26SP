# 操作系统 1 小时复习课程大纲

> 适用对象：已经听过课程、但知识点较零散或对算法题缺乏把握的同学。
>
> 课程依据：`Slides/ch0.pdf`—`Slides/ch10_part2.pdf` 与 `Notes/260302.md`—`Notes/260608.md`。
>
> 内容边界：只整理课件实际出现的主题；课堂科普和前沿案例仅作识别，不在 1 小时主讲中展开。

## 一、复习目标

完成 1 小时复习后，应能做到：

1. 用“抽象、隔离、复用资源”解释操作系统的作用，分清用户态、内核态、中断和系统调用。
2. 画出进程五状态图，解释 PCB、上下文切换以及 `fork()`、`exec()`、`wait()`、`exit()` 的配合。
3. 判断竞争条件，正确使用互斥锁和信号量解决生产者—消费者问题，并能识别死锁。
4. 根据甘特图计算等待、周转和响应时间，比较 FCFS、SJF/SRTF、RR、优先级与多级反馈队列。
5. 完成页号/页内偏移/物理地址转换，解释缺页、页面置换、Belady 异常与抖动。
6. 比较磁盘与 SSD，理解磁盘调度、FTL/GC、RAID 0/1/4/5/6 和 I/O 控制方式。
7. 从路径解析到块分配完整解释一次文件访问，比较连续、链式/FAT 与 inode 分配，并说明 FAT32、Ext、日志和 VFS 的作用。

## 三、主讲顺序与板书设计

### 0—3 分钟：一张全局图

板书主线：

```text
应用程序
   │ 系统调用
   ▼
操作系统内核 ── CPU 调度 / 进程同步 / 内存管理 / 文件与 I/O
   │ 驱动、控制器
   ▼
CPU、内存、磁盘、SSD 和其他设备
```

只强调三个关键词：

- **抽象**：进程抽象 CPU，虚拟内存抽象物理内存，文件抽象外存。
- **保护**：用户态代码不能随意执行特权操作。
- **复用**：多个任务共享有限的 CPU、内存和 I/O 设备。

### 3—8 分钟：OS 概览与结构

必须讲清：

- 中断让内核重新获得 CPU；系统调用是程序主动触发的受控入口。
- API、库函数、系统调用不是同一层：例如 `printf()` 可能最终调用 `write()`。
- 系统调用参数可通过寄存器、内存块地址或栈传递。
- 单体内核、分层、微内核、可加载模块的核心权衡是性能、隔离与可维护性。

一句检查题：“函数调用为什么通常不切换到内核态，而系统调用要切换？”

### 8—15 分钟：进程与线程

板书：进程地址空间、PCB、五状态图。

必须讲清：

- PCB 至少包含状态、程序计数器、寄存器、调度信息、内存信息、记账信息和 I/O 状态。
- 上下文切换保存旧进程 PCB、恢复新进程上下文，本身不完成用户任务，所以是开销。
- `fork()` 创建进程，`exec()` 替换用户空间，`exit()` 结束，`wait()` 回收退出状态。
- 僵尸进程已经结束但尚未被父进程回收；孤儿进程仍可能运行，只是父进程先结束。
- 同一进程的线程共享代码、数据、堆和打开文件；每个线程独有寄存器、程序计数器和栈。

### 15—26 分钟：IPC、同步与死锁

用 `count++` 被拆成“读—改—写”说明竞争条件。

必须讲清：

- 共享内存快但需要额外同步；消息传递更易隔离和跨机器通信。
- 临界区方案的四项要求：互斥、与速度/CPU 数无关、进步、有限等待。
- 自旋锁适合极短临界区；阻塞锁适合等待时间可能较长的情形。
- 信号量 `wait/P/down` 获取资源，`signal/V/up` 归还资源；两者必须原子执行。
- 有界缓冲区使用 `mutex=1`、`empty=N`、`full=0`，先取得计数资源，再取得互斥锁。
- 死锁四条件与四类处理：预防、避免、检测恢复、忽略。

板书生产者核心顺序：

```text
P(empty) → P(mutex) → 放入数据 → V(mutex) → V(full)
```

板书死锁判断：单实例资源分配图“有环即死锁”；多实例不能只凭有环下结论。

### 26—35 分钟：CPU 调度

板书四个时间量：

```text
周转时间 = 完成时刻 - 到达时刻
等待时间 = 周转时间 - CPU 运行时间
响应时间 = 第一次运行时刻 - 到达时刻
吞吐量 = 单位时间完成的任务数
```

必须讲清：

- FCFS 简单但有护航效应；SJF 平均等待时间最优但需预测 CPU burst。
- SRTF 是可抢占 SJF；RR 用时间片换响应性，时间片过大退化为 FCFS，过小则切换开销高。
- 优先级调度会饥饿，老化可缓解；多级反馈队列用行为动态调整优先级。
- 实时调度中 RM 使用静态优先级，周期越短优先级越高；EDF 动态选择截止期最近的任务。

现场至少画一次甘特图，并要求同学区分“等待时间”和“响应时间”。

### 35—46 分钟：内存与虚拟内存

板书地址转换：

```text
虚拟地址 = 页号 p + 页内偏移 d
页表[p] = 页框号 f
物理地址 = f × 页大小 + d
```

必须讲清：

- 代码、数据/BSS、堆和栈的用途；`malloc/free` 管理的是进程虚拟地址空间中的堆。
- 页表完成映射与保护，多级页表节省稀疏地址空间的页表内存，TLB 缓存近期转换。
- 缺页并不等于程序错误：合法页面不在内存时由 OS 调入；非法地址才终止进程。
- OPT 是理论下界；FIFO 不看使用规律；LRU 换出“最久没有被使用”的页；Clock 用访问位近似 LRU。
- FIFO 可能出现页框增加反而缺页更多的 Belady 异常。
- 页框不足导致抖动；工作集和缺页率可以指导页框分配或降低多道程序度。

### 46—52 分钟：外存与 I/O

必须讲清：

- HDD 延迟主要来自寻道和旋转；SSD 无机械移动，但不能原地覆盖，必须以块擦除。
- 磁盘调度比较 FCFS、SSTF、SCAN、C-SCAN、LOOK/C-LOOK；计算题以磁头移动柱面总数为指标。
- FTL 做逻辑—物理映射、垃圾回收和磨损均衡。
- RAID 0 提性能无冗余；RAID 1 镜像；RAID 4 专用校验盘；RAID 5 分布校验；RAID 6 双校验。
- 轮询占用 CPU 等待，中断由设备通知 CPU，DMA 适合大块数据传输。

### 52—60 分钟：文件系统

板书访问链：

```text
路径名 → 逐级读取目录项 → 文件元数据/inode → 数据块地址 → buffer/page cache → 用户缓冲区
```

必须讲清：

- 目录也是文件，目录项建立“名字到元数据编号”的映射。
- `open()` 返回整数文件描述符；`fopen()` 返回 C 标准库的 `FILE *`。
- 连续分配顺序/随机访问快但有外部碎片和增长问题；链式分配易增长但随机访问慢；FAT 集中链信息；inode 用直接和多级间接块兼顾大小文件。
- FAT32 的 FAT 项宽度、短/长文件名目录项、追加/删除/恢复过程；删除通常只撤销索引，不立刻擦除数据。
- Ext 按块组组织 superblock/GDT、位图、inode 表和数据块；硬链接共享 inode，符号链接保存路径。
- 日志把一次元数据更新组织为事务；提交记录使恢复时能区分完整与不完整事务。
- VFS 用统一接口屏蔽 FAT、Ext 等文件系统的实现差异。

## 六、授课方法

- 每个模块先回答“为什么需要”，再讲“数据结构/机制”，最后做“一道判断或计算”。
- 算法一律在纸上画状态：调度画甘特图，换页画页框表，磁盘调度画磁道线，死锁画资源分配图或矩阵。
- 不要求死记所有优缺点；从“性能、正确性、公平性、空间、实现复杂度”五个维度推导。
- 讲解结束使用复习知识文档末尾的 12 道自测题进行验收。
